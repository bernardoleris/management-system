# Estocaí frontend

Aplicação web independente, construída com React, TypeScript e Vite.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Validação e produção

```bash
npm run lint
npm run build
npm run preview
```

O frontend segue em desenvolvimento. Antes de integrar uma funcionalidade, confira o contrato correspondente na API Spring Boot.
